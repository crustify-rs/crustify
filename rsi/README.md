# RSI

What Crustify's ports learn that holds beyond the codebase it was learned in: one entry per
pattern of findings, at `<id>/<pattern>.md`, under the identifier of the requirement it
serves, stated without the names of any one codebase. A port's evolver writes an entry
here as soon as it proposes it, so that every agent of every port reads it and it takes
effect at once; the entry records its trial, and whether it was confirmed or rejected. A
change to the harness that an entry proposes, to the system prompt, a skill or a tool, is
adopted only at a port's end, or when the user asks, with the user's approval. The format
is the system prompt's Self-improvement section's.
