# RSI

What Crustify's ports learn that holds beyond the codebase it was learned in: one entry per
pattern of findings, at `<id>/<pattern>.md`, under the identifier of the requirement it
serves, stated without the names of any one codebase. A port's evolver commits an entry,
and any change to the harness it proposes, on the branch of Crustify that the port works
on, so that it takes effect at once; the entry records its trial, and whether it was
confirmed or rejected. It reaches `devel` only with the user's approval, at a port's end
or whenever the user asks. The format is the system prompt's Self-improvement section's.
