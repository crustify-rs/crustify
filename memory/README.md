# Memory

Crustify's generic memory: patterns of findings confirmed in a port and stated without the
names of its codebase, so that they hold for any. Each entry sits at
`<id>/<pattern>.md`, under the identifier of the requirement it serves, in the format a
port's own `.crustify/memory/` uses, as the system prompt's Self-improvement section
describes. An entry lands here only with the user's approval.
